PROJECT ASCENT - v0.1.0 (First Playable)
=========================================

A small precision platformer demo. Climb the route, learn the movement, and
reach the glowing amber goal on the final ledge.

HOW TO LAUNCH
-------------
1. Extract this ZIP to a folder of your choice.
2. Open the folder and double-click ProjectAscent.exe.
3. The game starts immediately. No installation needed.

CONTROLS
--------
  Move left/right   A / D  or  Left / Right arrows
  Jump              Space  or  W
  Dash (air)        Shift  or  J
  Restart run       R
  Show/hide help    Tab  or  F1

Gamepad support is also built in (left stick to move, south button to jump,
west button to dash, back/select to restart, start to toggle help).

HOW TO PLAY
-----------
Run, jump, and dash to the goal. A glowing amber marker marks the finish.
Touching it records your finishing time and immediately returns you to the
start for another attempt. You can also press R to restart at any time.

NOTES / KNOWN LIMITATIONS
-------------------------
- First Playable demo milestone: a single greybox proving ground, not the
  final game.
- Windows 64-bit (x86_64) only in this build.
- If Windows SmartScreen warns about an unknown publisher, choose "More info"
  then "Run anyway" - the file is unsigned.
- Requires the ProjectAscent.exe and ProjectAscent.pck files to stay in the
  same folder. Keep them together.
