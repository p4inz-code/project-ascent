## Compatibility (Windows 10 and 11)

- The game and launcher are 64-bit. Their imports are standard Windows system DLLs only (no Visual C++ install needed).
- The game uses the OpenGL Compatibility renderer and has ANGLE built in as a fallback when OpenGL is missing.
- Godot 4.7 lists Windows 10 as its minimum.
- Key bindings are physical keys, so non-QWERTY layouts work. Window sizes are clamped to the usable screen area.
- The launcher explains a missing, damaged or wrong-processor game file in plain words (`launcher/preflight.py`).

## Known and accepted

- `test_level` (above).
- Windows may show SmartScreen's "unknown publisher" warning on the first run: the game is not code-signed (owner decision).
- macOS and Linux builds cannot be run on the development PC; their zip layout is checked, not their behaviour.
