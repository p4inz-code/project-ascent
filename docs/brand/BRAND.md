# P4INZ brand system

A tiered identity: one studio brand on top, each game as its own brand under it, and every release or
campaign asset built from those two by fixed rules. See `brand_board_3840x2160.png` for all of it on one page.

Everything is pixel art on a grid. Each mark is built once at native pixel size and only ever scaled by whole
numbers, so the 16 px favicon and the 4K logo are the same pixels. Generated by `tools/studio_brand.py` (marks,
size ladder, brand board) and `tools/make_itch_assets.py` (the store and social kit, which also refreshes the
board).

## The 3D look

All marks share one treatment, the arcade block logo:

1. **Face.** Flat brand colour with a lit top edge and a shaded bottom bevel on every stroke.
2. **Extrusion.** The silhouette repeated down and to the right in stepped bands that darken with depth
   (studio marks in violet to deep indigo, the game logo in ice blue to navy).
3. **Outline.** One dark pixel (`#04070E`) around the whole solid, so it holds on any background.

No soft shadows, glows or gradients: depth comes only from whole pixels. Flat one-colour versions exist for
print and overlays.

## Tier 1: the studio, P4INZ INTERACTIVE LABS

The master brand. It signs every game and every page.

| Element | Spec |
| --- | --- |
| Symbol | The rocket: a 12 x 13 pixel mark with a pointed nose, a cyan porthole, swept fins and a two-tone flame. P4INZ makes games about going up. |
| Wordmark | `P4INZ` in custom bold 6 x 7 glyphs (two-cell strokes), with the 3D treatment. Drawn, not typed. |
| Descriptor | `INTERACTIVE LABS` in Silkscreen (SIL OFL, bundled) at its native 8 px grid, under the wordmark. |
| Handle | `@p4inz` in violet. The same handle on itch, GitHub and X. |
| Lockups | **Full** (symbol + wordmark + descriptor + handle), **Compact** (no handle), **Stacked** (centred, for squares and title cards), **Symbol** (the rocket alone: avatar, favicon). |
| Variants | 3D on dark (primary), 3D on light (dark descriptor), mono white, mono black. |

Studio palette: **Night** `#0A0D18`, **Violet** `#BE96FF`, **Violet light** `#EEE4FF`, **Violet shade** `#8054DE`,
**Outline** `#04070E`, **Lab cyan** `#5CC8FF` (porthole, links, accents only), **Flame** `#FF6A5C` / `#C85428`
(rocket flame and fins only).

Why violet: the colour grading test (`tools/studio_brand.py` has an `amber`, `violet` and `magenta` theme; set
`BRAND_THEME` to render the kit in each) put every studio mark on the real banner, cover and title card. Amber
had the most contrast (9.4:1 on the night sky) but it is also the game's trim colour, so studio and game blurred
together. Violet, brightened to 7.2:1 so it holds in thumbnails, gives the studio a colour of its own that sits
well next to the game's ice blue. Magenta clashed with the game's amber summit marker.

## Tier 2: the game, PROJECT ASCENT

A product brand with its own look, endorsed by the studio, never merged with it.

| Element | Spec |
| --- | --- |
| Logo | The `PROJECT ASCENT` pixel logo (`assets/pixel/logo.png`) with the ice-blue 3D extrusion and the amber summit marker. |
| Hero | Trevor: EVA-white suit, gold visor, orange scarf, life-support pack. Always the in-game sprite, scaled by whole numbers, and only one Trevor per asset. |
| World | The Spire at night: moon, dark skyline, lit windows (captured from the game by `tools/capture_keyart.gd`). |
| Tagline | `THE TOWER RE-ROLLS EVERY TIME YOU DIE` |
| Interface type | The game's own pixel face (Cyberpunk Craftpix Pixel) for game text. |

Game palette: **Spire night** `#0A0D18`, **Ice** `#6BC7FF`, **Suit white** `#EBE8DB`, **Visor gold** `#FFD159`,
**Trim orange** `#FFB347`, **Danger red** `#FF6A5C`.

The studio is violet and the game is ice and amber. The rocket's orange flame and cyan porthole are the
thread between them.

## Tier 3: release and campaign assets

Built only from Tier 1 and Tier 2 parts, by these rules:

1. **One focal point.** The game logo or Trevor leads; never both fighting at the same size.
2. **Endorsement, not co-branding.** The studio appears as a lockup in a corner, a quarter to half the width of
   the game logo, or as the line `A P4INZ INTERACTIVE LABS GAME`.
3. **Words.** The cover carries the title only (plus the small studio mark). Wider assets may add the tagline,
   one selling line and the platforms. Never more than three text lines besides the logo.
4. **Readable small.** Check every cover at half size; the logo must still read.
5. **Pixel honesty.** Real game art only: captures and sprites from the build, scaled by whole numbers.
6. **Dark ground.** Text sits on Night or on a soft dark panel faded into the art, never on bright sky.

## Files (`docs/brand/`)

Each mark is exported as a size ladder, largest first: about 3840, 2048, 1024, 512 and 256 px wide (the
largest whole-number scale under each width; the width is in the file name).

- `studio/`: `p4inz_lockup_full_3d`, `_compact_3d`, `_stacked_3d`, `_full_3d_on_light`, `_mono_white`,
  `_mono_black`, `p4inz_wordmark_3d`, `p4inz_wordmark_flat`, `p4inz_symbol_3d`
- `game/`: `project_ascent_logo_3d`, `_flat`, `_3d_on_night`, `trevor_idle`
- `avatar/`: `p4inz_avatar_2048` to `_64`
- `favicon/`: `p4inz_favicon_256` to `_16`, `favicon.ico`, `favicon_32.ico`
- `brand_board_1920x1080.png`, `brand_board_3840x2160.png`

All PNGs have transparent backgrounds except the avatar, favicon, `_on_night` and the board.

## Don't

- Stretch, rotate, smooth or scale the marks by a fraction (whole numbers only).
- Re-colour the marks (only the mono versions change colour).
- Put the studio wordmark bigger than the game logo on a game asset.
- Set the wordmark in a font: it is drawn, use the generated PNGs.
- Add glows, gradients or drop shadows that are not whole pixels.
- Show two Trevors in one asset.
