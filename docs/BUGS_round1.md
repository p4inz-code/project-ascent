Rule for this round: the player is supposed to be annoyed by the CHALLENGE, never by bugs or sloppy levels. Every item below has a root cause, a fix, and a test that fails if it comes back. "Seen" means checked in a captured frame of the real game; items still marked "not seen" have passed their tests but have not been looked at yet.
